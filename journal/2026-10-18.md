# Journal - 2026-10-18

I turned the starter sightings project into ASCII Garden. The strongest part is the small interaction loop: a slot has a character, watering changes it immediately, and returning later changes the available day. The visual work took longer than expected because the original CSS and JSX were compressed into long lines, which made small edits brittle. Replacing those presentation files made the result easier to reason about.

The most useful debugging moment was the Docker readiness failure. PostgreSQL itself was healthy, but the Node pool requested TLS because it only recognized localhost. The Compose hostname is `db`, so the connection was corrected at the pool configuration. I also learned that a hashed password does not solve authorization by itself. I later added signed sessions and scoped the garden queries to the session account.
